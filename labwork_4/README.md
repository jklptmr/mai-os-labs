# Лабораторная работа №4

Создание и использование динамических библиотек в C. Реализованы две библиотеки с функциями `gcd` (алгоритм Евклида и наивный алгоритм) и `area` (площадь прямоугольника и прямоугольного треугольника), а также две программы: с линковкой на этапе компиляции (`prog1`) и с динамической загрузкой во время выполнения через `dlopen`/`dlsym` (`prog2`).

## Сборка и запуск

```bash
cd labwork_4
make
./prog1
./prog2
```
