# Лабораторная работа №3 (Вариант 4)

Родительский процесс передает числа типа float дочернему процессу через именованную разделяемую память (shared memory + memory mapping) с синхронизацией через семафоры. Дочерний процесс делит первое число на последующие и выводит результат в файл. При делении на 0 дочерний процесс сообщает об ошибке и оба процесса завершают работу.

## Сборка и запуск

```bash
cd labwork_3
make
./parent
```
